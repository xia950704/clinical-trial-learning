# 07 — IIT 实战教程：从零搭建数据分析流水线

> 本教程参考 [build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) 模式，
> 用**真实 IIT 案例**带你从 CRF 数据一路走到统计报告。
>
> 不需要统计学背景，每步配有可运行的 R 代码。

---

## 教程结构

```
07-IIT实战教程/
├── Step-01-CRF到数据框/     ← 从 CRF 表格到干净 data.frame
├── Step-02-清洗流水线/       ← 去重 → 日期标准化 → 逻辑核查 → 缺失值
├── Step-03-描述统计与Table1/ ← 基线特征表自动生成
├── Step-04-疗效分析/         ← t检验 / KM 曲线 / 混合效应模型
├── Step-05-安全性分析/       ← AE/SAE 汇总 + 瀑布图
├── Step-06-报告自动生成/     ← R Markdown / Quarto 一键输出
├── data/                     ← 样例数据（合成或脱敏 IIT 数据）
└── README.md                 ← 本文件
```

## 学习顺序

```
Step 1 → Step 2 → Step 3 → Step 4 → Step 5 → Step 6
（每步约 30-60 分钟）
```
